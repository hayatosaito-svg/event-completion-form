# ビズリク｜案件終了アンケート

複数のイベントで使う参加後アンケートです。案件名・参加日・オンライン／オフラインを指定して回答できます。

参加を確認できる画像の添付は必須です。オンラインはイベント画面のスクリーンショット、オフラインは当日の服装・配布物・身につけたものなどの写真を案内します。

## 公開と受付

画面はGitHub Pagesで公開します。回答と画像は専用の受付APIへ送信し、運営担当者が参加状況を確認します。回答者の入力データや画像は、このリポジトリには保存しません。

## 更新

`event-completion-source.zip.b64` は、Vite/Reactのソースと固定した依存関係を収めたZIPをBase64形式にしたテキストです。GitHub Actionsが復元・展開し、テスト・ビルド後に公開します。変更時はソースを更新し、ZIPをBase64に変換して同ファイルを差し替えてください。

ローカルではBase64からZIPを復元して展開し、Node.js 22とpnpm 11.19.0で実行します。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm build
```
